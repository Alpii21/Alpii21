## 🚀 Featured Project

### 🦯 Smart Cane Object Detection Using FOMO & TinyML

An embedded computer vision system designed to help visually impaired users detect objects in front of them.

**Technologies:**

- ESP32-CAM AI Thinker
- FOMO (Faster Objects, More Objects)
- TinyML
- Edge Impulse
- Computer Vision
- C/C++
- Arduino IDE
- Embedded Systems

**Object Classes:**

- 🚗 Vehicle
- 🚪 Door
- 🪧 Pole

The system performs object detection directly on the embedded device and is designed to operate in real time and offline.
